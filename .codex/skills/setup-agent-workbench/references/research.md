# Исследования

Используй сэтап для разработки эксперимента, но не для скрытого улучшения измеряемого агента.

До запуска зафиксируй гипотезу, control/treatment, версии кода, модель, данные и split, бюджеты, метрику успеха и условие отклонения гипотезы. Учитывай стоимость, ошибки и отрицательный перенос.

Сопоставляй одинаковые условия. Не передавай held-out задачи в контекст, память или обратную связь обучающемуся агенту. Причина ошибки по одному trajectory остаётся гипотезой до экспериментальной проверки.

research_mode=true отключает только steering этого инструмента. Остальные глобальные/проектные хуки, skills и память необходимо контролировать отдельно в чистой среде.

Архив Galaxy — исторический материал. Сэтап не импортирует его старый движок и не доказывает эффективность Amnesia.
